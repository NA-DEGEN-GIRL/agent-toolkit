This is an unofficial, instruction-only adaptation. It reuses the visual-target / implementation / live-capture / critique loop while making bounded visual improvement of an existing game the primary task. The upstream skill itself also contains a follow-up workflow for existing products.

Main changes: genre-sensitive direction selection; protected gameplay contracts; game/scene/asset/UI/design-only scopes; shared-dependency checks; gameplay-size asset review; quality assessment instead of pixel matching; capability fallbacks; bounded iterations; and evidence-backed delivery.

The original copyright and MIT terms are preserved in `LICENSE`. No upstream example images or game assets are redistributed and no upstream endorsement is claimed.
